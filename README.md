# Hexis

Hexis is a private WordPress character-development review plugin for mariuszmirecki.pl.

The first iteration focuses on annual self-reflection across 32 virtues grouped into Intellectual, Intrapersonal (Resume), and Interpersonal (Eulogy) categories.

Core idea: character is not a completion score. Each virtue is reviewed as a direction of movement using a seven-position arrow from strong regression to strong progress, with an optional focus marker and reflection note.

## v0.1 scope

- Annual review for logged-in WordPress users
- Seven-position directional arrow
- Optional focus marker
- Optional reflection note
- Autosave
- Review completion status
- Multi-year history view
- Shortcode: `[hexis]`

No overall character score.
